        Getting your TOTP secret
        
      
          
        
        1. Log in to indfak2.dk in your browser and open your account security settings.
          2. 
        
        2. Start re-enrolling two-factor authentication. A QR code appears — and printed
            directly underneath it is a 16-character code, shown so you can type it into an
            authenticator by hand. That code is the secret.
          3. 
        
        3. Copy-paste that 16-character code into the field here. Copy it exactly as shown;
            if indfak2 prints it in spaced groups, delete the spaces first.
          4. 
        
        4. Finish the enrolment as usual — scan the same QR code with your phone’s authenticator app.
            Both it and this app then generate the same codes from that one secret.
          5. 
      
        
      
        
        The code is A–Z and 2–7 only — never a
        0, 1, 8 or
        9. It is not the 6-digit number your authenticator shows: that one
        changes every 30 seconds, while this one is the fixed seed it is generated from, and you copy it once.
      
        
      
        
        The repository also ships setup-totp.js, which drives the same flow in a
        scripted browser and reads the secret out of the QR code for you.
